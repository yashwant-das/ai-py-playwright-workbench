# Historical design records

The [v2 design](specs/2026-10-03-v2-showcase-simplification-design.md) records the
redesign constraints. Files in [plans/](plans/) describe completed implementation
phases; their commands and status statements are historical, not current setup
instructions. Preserve them when updating current guidance.

Start at the [README](../../README.md), [development guide](../development.md)
and [architecture guide](../architecture.md) for current behavior and commands.
Historical plans and design records are excluded from maintained-document
Markdown linting; this index remains in scope.
